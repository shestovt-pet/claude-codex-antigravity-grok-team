Проверяются аргументы с расширением `.js/.mjs/.cjs`, абсолютные Windows-пути с буквой диска или UNC, а на других системах — также абсолютные POSIX-пути. Общий `path.isAbsolute('/c')`, ошибочно принимавший ключ cmd за путь Windows, больше не используется для этой проверки.
