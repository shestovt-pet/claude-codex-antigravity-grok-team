## Реализовано

- Р2: краткая сводка показывает подсказки Codex по недельному расходу и Antigravity по остатку выбранной модели. Пороги: 50/80 % и 35/20/10 %. Неизвестный остаток не вводит ограничений. Для явного выбора модели в `team_status` передаётся `agy_model` (код или название из источника); без него берётся модель по умолчанию из источника квоты. При неизвестной модели и несовпадении аккаунтов остаток считается неизвестным. Квота Grok отмечена как невидимая, число поручений за 5 ч сохраняется.
- Р6: используется существующее поле `stage`: `рутина` либо `рутина: описание` (также допускается тире). Краткая сводка считает такие поручения за последние сутки. Это учёт явно помеченных поручений, а не автоматическая оценка их содержания; отсутствие меток не доказывает отсутствие рутины.
- Р7: `owner` и `work` доступны через общие схемы инструментов и передаются контекстом отдельного запроса. Напоминание фильтруется по меткам; без меток перечисляет просроченные работы с именем владельца. Одновременные вызовы и отказы проверки параметров не смешивают владельцев. Напоминание выводится перед заголовком один раз.
- Р8: диагностическое сообщение о пределе ответа превращается в понятный отказ с предложением размера части: половина числа строк материала, минимум 1, максимум 40. Цитата ошибки в ответе модели отказом не считается. Ошибка не запускает ожидание квоты, повтор чтения или переход протокола; автоматического деления нет.
- Р9: строка «Весь материал приложен, файлы не открывать» добавляется только при передаче через стандартный ввод. В исходном запасном режиме и при автоматическом переходе её нет, включая длинные поручения с файлами.
- Р10: ворота принимают окончания «блокирующее» и «блокирующих» при положительном целом числе. Прежняя форма сохранена; ноль, отрицательное число и лишний текст отклоняются. Обязательные голоса и остальные условия ворот не менялись.
- Продолжение по `roles`: `team_rules part=roles` выдаёт `rules/roles.md`, а `part=all` включает эту часть один раз. Чтение остаётся из зафиксированной версии `main`; рабочий текст правил в ответ не подмешивается. Часть `roles` добавлена также в подсказку при отсутствии краткой памятки.
