# Исправления по ревью, круг 1

Исправлено:
- Antigravity классифицирует квоту только при признаках неуспешного запуска. Успешный JSON с 429, rate limit или RESOURCE_EXHAUSTED в stderr остаётся успешным.
- Все чтения карточек Codex (включая архив, ожидание результата и очередь) используют common/cards.js: до 8 повторов после первой попытки при EBUSY/EPERM/EACCES или неполном JSON. Задержки — 50–400 мс, как у атомарной записи.
- Таймеры и обработчики событий Codex перехватывают синхронные исключения и отклонения обещаний. В журнал выводятся только разрешённые коды, без message/stack. Ошибка чтения при отмене позволяет повторить отмену позднее.
- При окончательном сбое сохранения выполняется попытка убрать временный файл; ошибка уборки подавляется. В тесте удаление подменено, файлы не удаляются.
- Несуществующий CODEX_PATH даёт ясный отказ «Codex CLI не найден» до запуска процесса.
- Новые файлы отформатированы; в перенесённом Antigravity отформатированы только добавленные блоки. Длинные строки литералов местами сохранены без изменения содержимого.
