1. Реестр и сохранность.
common/members-store.js хранит rev/phase A, members.json, members.json.last-good и members-log.jsonl. Запись через временный файл, fsync и rename под members.lock; временный отказ Windows при публикации повторяется ограниченное время, прежний снимок не удаляется. Писатель сверяет expected_rev; после короткого ожидания конкурентной записи проигравший получает MEMBERS_REV_CONFLICT. Зависший замок автоматически не снимается. Журнал содержит автора, время, причину, цитату, старый и новый снимки. last-good позволяет прочесть повреждённый основной файл с предупреждением. Если оба снимка недоступны, запуск и принятие прекращаются с причиной. Сохранившийся журнал/замок/backup не считается первой инициализацией. Defaults используются только для действительно нового состояния; чистое чтение и dry-run не создают файлов, первый сервер/писатель фиксирует начальный снимок. Незавершённая запись журнала не теряется молча: при несовпадении rev следующая запись останавливается.
