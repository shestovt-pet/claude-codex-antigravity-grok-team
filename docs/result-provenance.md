# Происхождение результатов

Контракт `common/provenance.js` добавляется в карточки и успешные meta Antigravity/Codex, карточки Grok, gate votes и read-only API коллегии. Старые карточки нормализуются при чтении без догадок по тексту.

- orchestration_role: роль поручения; никогда не право судьи.
- authenticated_client: историческое имя поля; client_identity_evidence прямо указывает configured_client_label_not_authentication. Это метка конфигурации, не новый механизм аутентификации.
- agent_instance и transport: отдельная сессия/поручение и транспорт.
- requested_text_model / provider_reported_text_model / evidence_level: запрос и декларация провайдера раздельно. В текущих CLI нет подтверждённого адаптера model-аттестации; поэтому reported остаётся unknown. API observe принимает только отдельное структурированное наблюдение от адаптера, не прозу.
- delegated_tool_chain: только разрешённые имена из структурированных событий. Аргументы и вывод инструментов не копируются; неизвестная или неполная цепочка не доказывает отсутствие делегирования.
- artifact_generator_service / provider_reported_artifact_model: unknown в текстовом job; сведения о доставленном изображении принадлежат отдельному artifact manifest.

Фильтрация событий не меняет существующий контракт хранения финального ответа. Произвольный текст ответа не считается достоверным происхождением. HMAC Grok подтверждает целостность канала; delivery_integrity.model_attestation=false. Ключ отменённого задания сохраняется до проверки позднего ответа в штатном .key, без автоматического уничтожения по таймеру.

Семья для старых Codex/Grok может быть известна только по настроенному маршруту, что маркируется configured_route. Это не подтверждение конкретной модели. Для Antigravity нужна хотя бы известная запрошенная модель. Противоречие запрошенной и объявленной семьи блокирует gate; одинаковая семья не даёт два независимых обязательных голоса.

Сборщик консилиума не решает вопрос принятия и не заменяет отсутствующего судью. Существующий access guard остаётся в силе. Квоты Claude Desktop и Antigravity/Claude показываются как различные источники; квота не является доказательством автора ответа.
