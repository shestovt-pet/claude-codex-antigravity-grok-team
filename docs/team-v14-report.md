## Решения в местах, где замысел не задаёт точный интерфейс

- Папка материала задаётся необязательным `team_work.folder`, без автоматической подстановки. При задании нужен абсолютный существующий каталог; заполненную папку менять нельзя. Нужна для ограничения material и .most/reviews.
- Постоянный id — UUID. Мост принимает id либо уникальное название этапа и сохраняет id. При обновлении без id прежний этап узнаётся по точному названию; для переименования нужно передать id.
- Версия файлов — SHA-256 от упорядоченного списка SHA-256 содержимого файлов, разделённого переводами строки. Это задаёт границы между файлами и учитывает порядок.
- Части распознаются по точному названию из author на границах слов. Семантического распознавания названий нет. Область проверки фиксируется до добавления опоры и чужих замечаний в бриф.
- Свежесть снимка Codex для разрешения замены — не более 60 секунд; сброс исчерпанного окна должен быть позже часа. Для Gemini требуется совпадение аккаунта источника.
- Закрытие работы с выданными этапами — `team_work action=close`; в сводке они перечисляются, процент принятого не растёт.
- Изменение файла и поздний отказ обнаруживаются при очередном обращении team_work/team_status; отдельного наблюдателя файлов нет.
- Обновление работы атомарно: при отказе перехода новые служебные записи этого обновления не сохраняются. Отрицательный fresh-файл можно зарегистрировать обновлением этапа в его текущем непринятом состоянии, затем передать override.
