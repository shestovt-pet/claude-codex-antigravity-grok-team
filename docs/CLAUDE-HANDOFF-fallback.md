# Запасной режим с токеном выведен из работы
Запасной режим с токеном выведен из работы в team-v19; порядок — rules/fallback.md.
Включает его слово пользователя «Claude отвалился» в чате Codex или Antigravity; хост, токен и отдельное состояние не нужны.
Команды `scripts\fallback.cmd` (enter, leave, confirm-*, jobs-*, actions-*, roles-*) отвечают отказом с этим указателем.
Роли по задаче — `scripts\roles.cmd`.
