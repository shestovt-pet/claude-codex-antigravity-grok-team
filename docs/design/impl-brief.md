## Общие требования
- Node ≥ 18, CommonJS, зависимости только @modelcontextprotocol/sdk (1.29.x, как в живом мосте) и zod 3. Один package.json в корне; серверы берут node_modules из корня (относительно своего файла, через require обычным путём).
- Имена серверов/инструментов/параметров — английские snake_case; ВСЁ человекочитаемое (title, description, ответы, ошибки) — по-русски, без транслита. registerTool с русским title.
- Каждый ответ — текст (не JSON). Первая строка: `<Помощник> · поручение <короткий id> · <СОСТОЯНИЕ> · <длительность по-русски>`; если у поручения есть stage — вторая строка `Этап: <stage> (работа <work>)`; последняя строка — `Дальше: …`. Формат — одна функция в common/format.js.
- Словарь состояний (common/states.js), строго эти слова: исполнение — В ОЧЕРЕДИ, ИДЁТ, ЖДЁТ КВОТУ, ОТВЕТ ПОЛУЧЕН, НЕ УДАЛОСЬ, ОТМЕНЯЕТСЯ, ОТМЕНЕНО, ОСТАНОВКА НЕ ПОДТВЕРЖДЕНА, ПОТЕРЯНО, НУЖНО РЕШЕНИЕ (Codex с записью после сбоя/квоты); перенос — ПЕРЕНОСИТСЯ, ПЕРЕНЕСЕНО, РЕЗУЛЬТАТ ПЕРЕНОСА НЕЯСЕН; Codex с записью — «ИЗМЕНЕНИЯ УЖЕ ВНЕСЕНЫ в <папку>».
