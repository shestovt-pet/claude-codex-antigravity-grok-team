# Команда из четырёх ИИ: Claude, Codex, Antigravity и Grok

*English summary below.*

Набор локальных серверов, который превращает Claude Desktop в дирижёра небольшой команды ИИ.
Claude ставит задачи и принимает решения, **Codex** критикует логику и пишет код, **Antigravity** пишет
литературный текст и проверяет тексты, **Grok** ищет источники, проверяет термины и гоняет тесты. Каждое
изменение самой связки проходит обсуждение замысла вчетвером, ревью итога, тесты и только потом установку —
без ручной работы человека.

Писалось для подготовки материалов к настольным ролевым играм и лекций, но годится для любой работы, где
полезен «второй и третий взгляд».

## Что внутри

| Сервер | Что даёт Claude |
| --- | --- |
| `team` | состояние команды и квоты (`team_status`), правила (`team_rules`), учёт работ с процентом готовности (`team_work`), изменения самой связки через ворота голосов (`team_change`) |
| `codex` | поручения Codex: ревью только чтением, код — только в рабочей копии изменения |
| `antigravity` | поручения Antigravity: текст, правка, замечания; на диск пишет только мост после проверки |
| `grok` | поручения Grok через вебхук его рутины; ответы подписываются и проверяются |

Правила команды — в `rules/`, накопленный опыт — `lessons.md`, скилл для Claude — `skill/helpers/SKILL.md`,
устройство и развёртывание подробно — `docs/architecture.md`.

## Требования

- Windows 10 или 11.
- [Claude Desktop](https://claude.ai/download) — обязательно (он дирижёр).
- [Node.js](https://nodejs.org) 18 или новее, [Git for Windows](https://git-scm.com); `tar` в Windows 10/11 встроен.
- Помощники — по желанию, каждый со своей подпиской: [Codex](https://openai.com/codex) (приложение или CLI),
  [Antigravity](https://antigravity.google) (нужен доступ к Antigravity и его консольная утилита `agy` — через
  неё мост отдаёт поручения), Grok (рутина Grok Bot с вебхуком — см. ниже). Без помощника связка работает, но
  его голоса и поручения недоступны.

## Установка

### Вариант 1: через git (удобно обновлять)

```powershell
git clone https://github.com/shestovt-pet/claude-codex-antigravity-grok-team.git C:\most
cd C:\most
.\setup.cmd --dry-run   # проверка: что найдено и что будет сделано, ничего не меняется
.\setup.cmd             # установка
```

### Вариант 2: архивом ZIP (скачать в браузере, без git clone)

На странице репозитория: зелёная кнопка **Code → Download ZIP**. Распакуйте в папку, например `C:\most`, и
дважды щёлкните `setup.cmd` (или в PowerShell из этой папки: `.\setup.cmd`). Git всё равно нужен на компьютере: установщик
сам создаст в папке локальный репозиторий из одного коммита — релизы собираются из него.

### Что делает установщик

Папка может быть любой, `C:\most` — только пример; установщик берёт папку, в которой лежит сам.

1. Проверяет Windows, Node.js 18+, git, tar и npm и объясняет, чего не хватает. Ничего не пишет, пока проверки
   не пройдены.
2. Проверяет подключения в настройках приложений: запись с именем `team`, `codex`, `antigravity` или `grok`,
   которая указывает не в эту папку (например, ваш другой сервер с таким же именем или вторая установка связки),
   считается чужой. Тогда установка останавливается, называет запись и ничего не меняет — уберите запись сами
   или запускайте установку из той папки, куда она указывает.
3. Собирает релиз из ветки `main` в `live\<коммит>` (зависимости ставит npm) и проверяет запуск всех четырёх
   серверов.
4. Подключает серверы к найденным приложениям: Claude Desktop (обычная установка и из Microsoft Store),
   Codex (`%USERPROFILE%\.codex\config.toml`), Antigravity (`%USERPROFILE%\.gemini\config\`). Остальные записи
   в этих файлах сохраняются, рядом создаётся `.prev` для отката. Не найденные приложения пропускаются с
   объяснением.
5. Дописывает Codex и Antigravity раздел правил связки в их `AGENTS.md` (между метками `most:begin`/`most:end`;
   ваш текст в файле не меняется); при повторной установке обновляет этот раздел. Перед правкой — копия `.prev`.
6. Печатает, что подключено и что пропущено.

Окно установщика ждёт нажатия клавиши, чтобы итог можно было прочитать. Потом перезапустите Claude Desktop и в
новом чате попросите: «вызови team_status». Повторный запуск безопасен:
тот же релиз не пересобирается, записи не дублируются. `.\setup.cmd --dry-run` ничего не пишет.

## Grok (по желанию)

Grok не обязателен, и установщик его не настраивает. Он подключается не как приложение, а через **рутину Grok
Bot с вебхуком**, которая работает на этом же компьютере с Windows (рутине нужен доступ к папке связки и
PowerShell). Пошагово:

1. В Grok Bot создайте рутину с триггером «вебхук». Сервер `grok` отправляет на вебхук POST с заголовком
   `Authorization: Bearer <ключ>` и телом JSON:
   `{ "id": "<номер>", "brief_path": "<путь брифа>", "reply_path": "<путь ответа>", "secret_hex": "<разовый секрет>" }`.
   Вебхук должен ответить `200` и JSON с `success: true` и `runUuid` — так сервер понимает, что поручение принято.
2. Инструкция рутине: прочитать файл `brief_path` и выполнить поручение из него; ответ записать в UTF-8 без BOM в
   `reply_path` + `.tmp`, подписать и переименовать в `reply_path`. Формат ответа (первая строка, вердикт,
   строка `КОНТРОЛЬ <HMAC-SHA256>` и строка `КОНЕЦ ОТВЕТА`) и готовая команда PowerShell для подписи приходят в
   каждом брифе; подробно — `rules/grok.md`. Секрет `secret_hex` живёт только в теле вебхука, его нельзя
   сохранять и выводить.
3. Скопируйте адрес и ключ вебхука из панели этой рутины в Grok Bot и создайте сами файл
   `<папка связки>\state\grok-webhook.json`: `{ "url": "https://api2.cursor.sh/automations/webhook/…", "key": "…" }`.
   Другие адреса сервер не принимает («адрес вебхука не похож на Grok Bot»). Папка `state\` не попадает в git.
   Ключ никому не передавайте, в том числе в чат с Claude: сервер читает его только из этого файла.
4. В Grok Bot разрешите рутине без подтверждения действия только в папках `state\grok`, `works` и `.work`
   папки связки — иначе каждое поручение будет ждать вашего нажатия. Шире правило не делайте.
5. Проверка: `team_status` покажет «Grok: мост настроен»; затем попросите Claude дать Grok пробное поручение и
   показать ответ.
6. Смена ключа: создайте в Grok Bot новый ключ и перезапишите `state\grok-webhook.json`.
7. Подтверждения. Действия вне папок из шага 4 (например, полный прогон тестов во временной папке) Grok Bot
   показывает как запрос «Run a task on Grok Bot's computer», и у запроса есть срок. Если вас нет у экрана, срок
   истекает («Срок подтверждения истек»), и поручение через 60 минут считается потерянным. Если вы доверяете
   рутине most-bridge, выберите в карточке запроса «Всегда разрешать» — тогда такие поручения не ждут вас.

## Как пользоваться

Говорите с Claude обычными словами: «попроси Codex проверить…», «пусть Antigravity напишет…», «Grok, найди
источники…». Claude сам ведёт поручения, показывает процент готовности на каждом принятом этапе и честно
отделяет сделанное от запланированного. Правила, по которым он работает, — `team_rules`; кратко —
`rules/brief.md`.

Изменение самой связки: замысел → голоса Codex и Antigravity (Grok — совещательно) → код в отдельной рабочей
копии → полный прогон тестов → ревью итога → слияние → установка с перезапуском Claude и уборкой старых релизов.
Порядок — `rules/common.md`, раздел «Изменение инструментария».

## Обновление и откат

- Обновиться до новой версии из GitHub: `git pull`, затем снова `.\setup.cmd`.
- Откатить подключения на предыдущий релиз: `node tools\deploy.js --rollback`.
- Публикация своей копии на GitHub и её обновление — порядок в `docs/publish.md`.
- Тесты: `node tests\run.js` (около 6 минут; журнал — `tests\windows-test-output-<папка>.txt`).
- Если ставили из ZIP: скачайте новый ZIP, распакуйте поверх в ту же папку с заменой файлов и снова
  запустите `setup.cmd` — установщик зафиксирует новую версию коммитом и соберёт из неё релиз. Удалённые в новой
  версии файлы при распаковке поверх остаются; если это важно — ставьте через git.

## Ограничения и безопасность

- Только Windows: перезапуск Claude, подключения и проверка процессов написаны под неё.
- Нужны собственные подписки на Claude и на каждого помощника; квоты видны в `team_status`.
- Все данные — поручения, ответы, журналы — лежат локально в `state\` папки связки; телеметрии нет, наружу
  связка ничего не отправляет, кроме поручений самим помощникам (Codex, Antigravity, вебхук Grok).
- Установщик меняет только записи `team`/`codex`/`antigravity`/`grok` в настройках найденных приложений и раздел
  между метками в `AGENTS.md` помощников; перед каждой правкой — копия `.prev`.
- Интерфейс и правила — на русском.
- Это рабочий инструмент одного пользователя, выложенный как есть: без гарантий (см. LICENSE).

## English summary

Local MCP servers that turn **Claude Desktop** into the conductor of a four-model team: **Codex** (critique and
code), **Antigravity** (writing and text review), **Grok** (sources, term checks, test runs). Every change to the
toolkit itself goes through design votes, review, tests and an automatic deploy with Claude restart and cleanup.
Windows 10/11, Node.js 18+, Git. Install: clone (or Download ZIP), run `setup.cmd --dry-run`, then `setup.cmd`,
restart Claude Desktop. The installer refuses to overwrite MCP entries named team/codex/antigravity/grok that
point elsewhere. Grok is optional and connects through a Grok Bot webhook routine (`state\grok-webhook.json`). Interface
and rules are in Russian. MIT license.
