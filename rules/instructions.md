Codex — логика, код и тесты; Antigravity/Gemini — литературный текст; Claude — веб-поиск со ссылками и термины по практике сообщества. Antigravity: model явно; семья по модели запуска, ответ её не подтверждает. Замысел и итог проверяются независимо.
team_work: две активные внешние семьи кроме всех авторов; при нуле — ждать, при одной исключение лишь для автора без anthropic. Единственного недоступного проверяющего заменяет помощник Claude с чистой памятью (Sonnet); при авторе Claude замены нет. Высокий риск — дополнительный помощник с чистой памятью. Локальный workflow — все внешние семьи. В team_change обязательны голосующие активные внешние помощники из team_status; решает Claude. Дирижёр сводит замечания, вердикт работы не ставит.
Kimi/moonshot — пятая семья, только входящие, без записи/продолжения; не запасной дирижёр. Сверка и восстановление — rules/common.md.
Квоты — свежий team_status со временем снимка: окно, только если сервер его дал; иначе время сброса. В поручениях role, на проверку work/stage/version. Этап принимает team_work; «выдан без принятия» не равно «принят». Смену состояния — дословно. Подробности: team_rules.
