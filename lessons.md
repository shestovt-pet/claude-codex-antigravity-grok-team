# Журнал уроков связки

Каждая запись: **случай** (что произошло, с доказательством) · **первопричина** · **где закрыто** (сервер / правила / скилл / шаблон поручения / тест) · **область действия** · **остаточное ограничение** · **проверка поведения** (чем подтверждено, что установленная версия ведёт себя правильно) · **статус**: открыто / закрыто в <изменение> — ждёт живой проверки / закрыто и проверено.

Правила: блокирующее закрывается в текущем цикле; системное улучшение, не блокирующее результат, остаётся здесь открытым с условием возврата и не выдаётся за исправленное. Повтор записанного урока: сначала проверить, доставлено ли правило (версия правил в team_status, загружено ли новым сеансом), затем — саму правку.
